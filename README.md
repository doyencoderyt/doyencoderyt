# 👋 Welcome to Doyen Coder

**Doyen Coder** is a startup-driven open-source initiative focused on delivering modern, maintainable, and enterprise-grade applications using **Java (Spring Boot)** and **Angular**. We aim to bridge the gap between learning and real-world application development.

---

## 🌟 Our Mission

To empower developers and teams with high-quality, production-ready codebases and tools that accelerate digital product development — whether you're launching a **startup MVP**, building an **enterprise-grade system**, or contributing to **open-source innovation**.

---

## 🎯 Our Vision

- 🔗 Create a strong community of collaborative and curious developers
- 🛠️ Build reusable, scalable software components
- 📚 Provide practical learning resources for full-stack development
- 🚀 Support early-stage startups and enterprise engineers with open templates

---

## 🛠️ Tech Stack We Love

### Frontend
- Angular (Reactive Forms, Routing, Lazy Loading)
- Bootstrap / Angular Material
- HTML5 / CSS3 / TypeScript

### Backend
- Java 17+ / Spring Boot (MVC, Security, JPA, Validation)
- RESTful APIs
- Microservices (in progress)

### Database
- PostgreSQL / MySQL
- JPA / Hibernate / Flyway for migrations

### DevOps & Tools
- Git / GitHub / GitHub Actions
- Postman / Swagger
- Docker (coming soon)
- VS Code / IntelliJ IDEA

## 🤝 How to Contribute

We welcome developers of all skill levels to contribute. Here's how you can get involved:

1. 🍴 Fork the repository
2. 🛠️ Make your changes
3. 📬 Submit a pull request
4. 🔍 Discuss ideas in issues or start a new feature request

For larger changes, open an issue first to discuss what you’d like to contribute.
